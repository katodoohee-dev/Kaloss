# Party Word Guess — Design Master

This folder preserves the visual source extracted from the real Lovable project used as the canonical design reference.

## Visual DNA
- Warm cream / off-white base
- Pastel peach/coral/pink/butter/mint/lavender/sky palette
- OKLCH tokens
- Rounded / pill geometry
- Warm diffuse shadows
- Spring-like interaction motion
- Thai-friendly Mali + Noto Sans Thai typography
- Inline SVG mascot Bloop
- Landscape-first gameplay treatment
- Safe-area and short-landscape CTA rules

## Canonical source
Lovable project: https://lovable.dev/projects/bd224c83-d771-4be0-a8c5-fc0b24987609

## Runtime master
The root `index.html` is a standalone visual master with the five primary screens and mock interaction flow, suitable for Render static hosting while the React source is being developed.
