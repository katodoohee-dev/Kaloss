# Party Word Guess

Frontend design master for Party Word Guess, based on the source design system extracted from the Lovable project.

## Deploy on Render

This repository includes `render.yaml` for a Render Static Site.

- Build command: none
- Publish directory: `.`
- Entry point: `index.html`

## Included

- `index.html` — standalone visual prototype
- `source-master/` — extracted reusable visual source, tokens, mascot, controls and supporting design code
- `render.yaml` — Render static-site configuration
